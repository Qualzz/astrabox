# Changelog

## 0.1.0 — 2026-09-30

Initial standalone open-source preview of ASTRABOX.

- Hardware-independent local application with optional Raspberry Pi deployment.
- Lunar scene split into isolated factories, preserving geometry and art direction.
- Four example cartridges: Meteor Dodge, Line Pong, Quiet Breakout and Tiny Stack.
- Persistent text/voice harness, cartridge-owned visuals and live-state migration.
- Shared physical input, player joining, CRT, scores, MIDI and CC0 sound library.
- Correct runtime dependency classification, pinned versions and account-specific model settings.
- Native Codex launcher without shell-shim dependence; startup diagnostics.
- Fixed the browser receiver binding that prevented menu MIDI loading.
- Fresh browser screenshots, installation guides, asset notices and automated checks.

This is a local experimental release, not a hosted service or a hostile-code sandbox.
