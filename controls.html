RÉGLAGE DES CONTRÔLES

Joystick · A B X Y L1 R1 L2 R2 · START · CODEX

Menus : A pour valider, B pour revenir. En partie, A/B restent les actions du jeu.

Deux boutons supplémentaires seulement : le bouton marqué COIN sert de START, l’autre de CODEX. START P2 permet de rejoindre un jeu à deux.

TEST DES ENTRÉES

Pour quitter un jeu : maintenez START pendant 3 secondes (P1 ou P2). Échap fonctionne aussi au clavier. Passez les boutons d’action absents. Les deux encodeurs identiques restent liés à leur port/index : recalibrez si le système les réordonne.
